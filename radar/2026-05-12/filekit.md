FileKit is a Kotlin Multiplatform library by vinceglb that provides a unified API for file picking and saving across Android, iOS, desktop, and web. It abstracts platform-specific file system dialogs and permissions behind a simple, coroutine-friendly interface, making file handling straightforward in shared KMP codebases.
