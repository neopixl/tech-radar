The `gradle-android-test-aggregation-plugin` by gmazzo aggregates unit and instrumented test results and code coverage reports from all modules in a multi-module Android project into a single unified report. This is especially valuable in modularized builds where running tests across many modules would otherwise produce scattered, hard-to-consolidate outputs.
