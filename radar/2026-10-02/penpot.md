Penpot is an open-source design and prototyping platform that runs in the browser and can be self-hosted. It is built on open web standards (SVG, CSS, HTML), with CSS Grid and Flex layouts and design tokens, so designs map closely to code.

#### Should be used in a new project if:

* The client requires an open-source or self-hosted design tool, for example for data sovereignty.
* You want designers and developers to share the same layout model (Flex and Grid) and tokens.

#### Should not be used in a new project if:

* The client's design team and assets are already in Figma, which remains our default design tool.
