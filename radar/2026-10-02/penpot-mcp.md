Penpot's official MCP server lets AI agents read, change and create content in Penpot design files. It connects to Penpot through a dedicated plugin that uses the Penpot Plugin API, and supports design-to-code, code-to-design and design-to-design workflows. Its code is now part of the main Penpot repository.

#### Should be used in a new project if:

* The project's designs are in Penpot and you want agents to implement screens from them, or to update the designs from code.

#### Should not be used in a new project if:

* The designs are in Figma (see Figma MCP).
* You need a fully proven workflow: we are still trialling it.
